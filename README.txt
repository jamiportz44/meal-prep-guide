Before submitting:
1. Replace YOUR-USERNAME and YOUR-REPOSITORY in robots.txt and sitemap.xml with the real GitHub Pages address.
2. Upload these files to a GitHub repository and enable GitHub Pages in repository Settings > Pages.
3. Test the public URL in a private/incognito browser window.
4. Add meaningful commits on different days as your project develops. Do not fake commit dates.
5. Verify the exact final URL in Google Search Console, submit sitemap.xml, and capture the requested baseline numbers and screenshots.
6. Add your actual live URL and repository URL to your report.
